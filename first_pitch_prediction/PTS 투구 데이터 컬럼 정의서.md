# PTS 투구 데이터 컬럼 정의서 (2017–2020)

Oct 29, 2026 · @정인

`pts_pitch_2017_2020.xlsx`의 65개 컬럼과 `pitcher_list` 시트를 정의하고, 범주형 컬럼은 나올 수 있는 값을 전부 적었다. 값 목록과 개수는 실제 데이터(197,102개 투구)에서 뽑았고, 코드 정의서가 없어 뜻을 데이터로 추정한 항목은 \*\*(추정)\*\*으로 표시했다.

`pit_result`·`how`·`place_sc`의 뜻과 `field_if`의 F·L·G·T는 회사 코드표 기준이다. 코드표에 없는 기호만 데이터로 추정했다.

## 기본 구조

한 행이 공 하나(투구 1개)이고, 공 하나를 구분하는 키는 `gameID` + `pit_no`다(중복 0건).

| 시트 2 `pitcher_list` | 41행. 투수 코드·이름·투구 수 + 별도 팀 코드표 |

## 투구 위치·존 컬럼

**`zonex`·`zoney`·`pz_x`·`pz_y`는 분석에 쓰지 않는다(회사 안내).** 시스템 그래픽에서 입력한 값이라 칸이 실제로 어디인지 알 수 없다. 투구 위치는 `CROSS_PLATE_X`·`CROSS_PLATE_Z`로 본다.

| 항목 | 기준 |
| --- | --- |
| 시점 | `CROSS_PLATE` 값은 포수 시점. X는 포수 기준 오른쪽(1루 쪽)이 + |
| 스트라이크존 좌우 | X = −21.6cm \~ +21.6cm (홈플레이트 폭 17인치의 절반). `CROSS_PLATE_X` × 30.48로 cm 변환 |
| 스트라이크존 상하 | `BOTTOM_SZ_KOR` \~ `TOP_SZ_KOR` (m, ×100으로 cm). `CROSS_PLATE_Z`는 ft이므로 × 30.48로 맞춰 비교 |
| 참고용 컬럼 | `zonex`·`zoney` 0–8, `pz_x` 10–220, `pz_y` 10–281. zonex는 pz\_x를 25픽셀씩, zoney는 pz\_y를 32픽셀씩 자른 값이다 |
